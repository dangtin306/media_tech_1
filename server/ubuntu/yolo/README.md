# YOLO26 Ubuntu

Hướng dẫn đưa project YOLO26 từ Windows lên Ubuntu để train và chạy inference.

## Luồng chuẩn

```text
Windows sửa code
    -> git commit / git push
Ubuntu git pull
    -> kích hoạt Conda env YOLO
    -> đặt model và dataset ngoài Git
    -> train hoặc inference
```

Đọc theo thứ tự:

1. `guide_folder.md`
2. `guide_env.md`
3. `guide_install.md`
4. `guide_run.md`
